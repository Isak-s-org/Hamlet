# Chat Send (Phase 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Type into a cmux session from its chat overlay, with a "/" menu of that session's commands.

**Architecture:** A new daemon module, `terminal.ts`, cleans the text and pastes it into the session's cmux surface. It makes one `cmux rpc terminal.paste` call that also submits. A new endpoint, `POST /api/sessions/:id/send`, guards that call. `commandsIn` reads the transcript's `skill_listing` lines, and `ChatFeed` streams them as a `{ commands }` chat event. The web overlay gets a composer with a "/" menu, built on pure helpers in `chat-format.ts`.

**Tech Stack:** TypeScript (ES2023, ESM), Node 22, Fastify 5, Vite 8 plus plain DOM, `node:test` through `tsx`, pnpm workspaces.

**Spec:** `docs/superpowers/specs/2026-10-12-chat-send-design.md`

## Global Constraints

- No new runtime dependencies.
- `SEND_CAP` = 64 KB (UTF-8 bytes) per message. The cmux call has a 5 s timeout.
- The daemon picks the target surface from `bots.get(id).terminal` only. The browser never names a surface.
- cmux is run through `execFile` with an argument array, never a shell.
- Transcript text (command names and descriptions) is HTML-escaped before it reaches `innerHTML`.
- Keys in the composer:
  - Enter sends and Shift+Enter adds a newline.
  - With the menu open, ↑/↓ moves and Tab or Enter completes.
  - ESC closes the menu, then the chat.
- Code style follows the surrounding code: double quotes, semicolons, 2-space indent, short `//` or `/** */` comments that explain *why*, `node:test` with `assert/strict`.
- `pnpm typecheck` and `pnpm test` pass after every task.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Messages containing escape sequences**, such as a pasted log with ANSI colors. They are stripped before reaching the TUI, so they can't drive it. Tested in Task 1 (`cleanText`).
2. **A send while a permission prompt is held.** It gets a 409, so the text can't land in the dialog. Tested in Task 3.
3. **Sessions outside cmux.** They get a 422 from the daemon, and the composer is read-only and says why. Tested in Task 3 (server) and Task 4 (`sendBlock`).
4. **Command names or descriptions containing HTML** from a malicious skill. They show as literal text in the menu. Tested in Task 4 (`menuHtml`).
5. **A transcript with no listing, or a malformed one.** The menu shows the built-ins, and the feed never throws. Tested in Task 2.

```ts
import { promisify } from "node:util";
import { SEND_CAP, type Bot } from "@hamlet/shared";

const run = promisify(execFile);
type Terminal = NonNullable<Bot["terminal"]>;
export type CmuxTerminal = Extract<Terminal, { kind: "cmux" }>;

/** C0 controls other than tab and newline, DEL and C1: an ESC that reached the TUI could drive it. */
const CONTROL = /[\u0000-\u0008\u000b-\u001f\u007f-\u009f]/g;

/** Text as it may reach the terminal, or why not. */
export function cleanText(text: string): { text: string } | { error: "empty" | "too-long" } {
  const clean = text.replace(/\r\n?/g, "\n").replace(CONTROL, "").trimEnd();
  if (!clean.trim()) return { error: "empty" };
  if (Buffer.byteLength(clean) > SEND_CAP) return { error: "too-long" };
  return { text: clean };

  JSON.stringify({ workspace_id: t.workspaceId, surface_id: t.surfaceId, text, submit_key: "return" }),
];

export async function sendText(t: CmuxTerminal, text: string): Promise<void> {
  await run("cmux", pasteArgs(t, text), { timeout: 5000 });
}

}
```

```ts
const DESCRIPTION_CAP = 200;

/**
 * The commands a `skill_listing` attachment lists: the skills, custom and plugin commands the session
 * can run. `initial` lists replace what came before; later ones add to it. Never throws.
 */
export function commandsIn(line: string): { commands: Command[]; initial: boolean } | undefined {
  // Every transcript line passes through here; most can be skipped without parsing.
  if (!line.includes('"skill_listing"')) return;
  try {
    const a = JSON.parse(line)?.attachment;
    if (a?.type !== "skill_listing" || !Array.isArray(a.names) || !a.names.every((n: unknown) => typeof n === "string")) return;
    // `content` has one "- <name>: <description>" row per name; names never contain ": ".
    const described = new Map<string, string>();
    for (const row of String(a.content ?? "").split("\n")) {
      const at = row.indexOf(": ");
      if (row.startsWith("- ") && at > 2) described.set(row.slice(2, at), row.slice(at + 2).trim());
    }
    const cut = (d: string) => (d.length > DESCRIPTION_CAP ? `${d.slice(0, DESCRIPTION_CAP - 1)}…` : d);
    return { initial: a.isInitial !== false, commands: (a.names as string[]).map((name) => ({ name, description: cut(described.get(name) ?? "") })) };
  } catch {
    return;
  }
}
```

```ts
app.post(`${API_PREFIX}/sessions/:id/send`, async (request, reply) => {
  const { id } = request.params as { id: string };
  const { text } = (request.body ?? {}) as { text?: unknown };
  if (typeof text !== "string") return reply.code(400).send();
  const clean = cleanText(text);
  if ("error" in clean) return reply.code(clean.error === "empty" ? 400 : 413).send({ error: clean.error });
  const bot = bots.get(id);
  if (!bot) return reply.code(404).send();
  // Typed text would land in the terminal's permission dialog.
  if (bot.permission) return reply.code(409).send();
  if (bot.terminal?.kind !== "cmux") return reply.code(422).send();
  try {
    await sendText(bot.terminal, clean.text);
  } catch (e) {
    const msg = String((e as { stderr?: string }).stderr || (e as Error).message).trim();
    return reply.code(502).send({ error: msg });
  }
  log({ kind: "sent", sessionId: id, chars: clean.text.length });
  return reply.code(204).send();
});
```

```ts
export type MenuCommand = Command & { builtin?: true };
const MENU_MAX = 50;

/** What to filter the "/" menu by, while the whole message is a lone `/word`. */
export function menuQuery(text: string): string | undefined {
  return /^\/(\S*)$/.exec(text)?.[1];
}

/** Name prefix matches first, also counting the part after a plugin's "plugin:" prefix, then other matches; each group A–Z. */
export function matchCommands(query: string, list: MenuCommand[]): MenuCommand[] {
  const q = query.toLowerCase();
  const starts = (c: MenuCommand) => c.name.toLowerCase().startsWith(q) || c.name.toLowerCase().split(":").at(-1)!.startsWith(q);
  const byName = (a: MenuCommand, b: MenuCommand) => a.name.localeCompare(b.name);
  const first = list.filter(starts).sort(byName);
  const rest = list.filter((c) => !starts(c) && c.name.toLowerCase().includes(q)).sort(byName);
  return [...first, ...rest].slice(0, MENU_MAX);
}

/** The session's commands plus the built-ins the transcript doesn't list. */
export function allCommands(session: Command[]): MenuCommand[] {
  const names = new Set(session.map((c) => c.name));
  return [...session, ...BUILTIN_COMMANDS.filter((c) => !names.has(c.name)).map((c) => ({ ...c, builtin: true as const }))];
}

export function menuHtml(list: MenuCommand[], active: number): string {
  return list
    .map(
      (c, i) =>
        `<li role="option" id="chat-cmd-${i}" data-i="${i}" aria-selected="${i === active}"><span class="cmd">/${esc(c.name)}</span><span class="desc">${esc(c.description)}</span>${c.builtin ? `<span class="tag">built-in</span>` : ""}</li>`,
    )
    .join("");
}

/** Why this bot can't be sent to right now. `readOnly`: typing is pointless too, not just sending. */
export function sendBlock(bot: Bot | undefined): { reason: string; readOnly: boolean } | undefined {
  if (!bot) return { reason: "This session has ended.", readOnly: true };
  if (!bot.terminal) return { reason: "Read-only: Hamlet can't find this session's terminal.", readOnly: true };
  if (bot.terminal.kind !== "cmux") return { reason: "Read-only: sending works for cmux sessions only. This one runs in Windows Terminal.", readOnly: true };
  if (bot.permission) return { reason: "Answer the WAITING prompt first.", readOnly: false };
}
```
