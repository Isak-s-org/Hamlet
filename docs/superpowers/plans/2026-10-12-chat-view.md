# Chat View (Phase 1, Read-Only) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open a session's full conversation from its bot in a full-screen overlay. The overlay updates live from the session's Claude Code transcript.

**Architecture:** The daemon follows each session's transcript JSONL, and its subagents' transcripts, with a shared incremental reader (`JsonlTail`). A pure `toEntries()` turns each line into `ChatEntry`s. A per-session `ChatFeed` serves them over a new SSE endpoint, `GET /api/sessions/:id/chat`. The web app adds a `chat.ts` overlay module that renders entries append-only, with collapsed tool cards built lazily, and pure, tested formatting helpers in `chat-format.ts`.

**Tech Stack:** TypeScript (ES2023, ESM), Node 22, Fastify 5 (daemon), Vite 8 plus plain DOM (web), `node:test` run through `tsx`, pnpm workspaces.

**Spec:** `docs/superpowers/specs/2026-10-12-chat-view-design.md`

## Global Constraints

- No new runtime dependencies: no markdown or diff library. Plain text plus fenced code, and a line-listing diff.
- Every `/api` route needs the daemon token (already enforced by the `onRequest` hook). The browser never sends a file path. The daemon only reads paths it learned from hooks or the session registry.
- Caps:
  - `TEXT_CAP` = 32 KB per tool result and per tool-input string.
  - `BATCH` = 500 entries per SSE message.
  - `MAX_LINE` = 8 MB for an unfinished chat line.
  - The title reader keeps 64 KB.
  - Poll every 500 ms. Drop a feed 30 s after its last viewer leaves.
- Everything from a transcript is untrusted text. It is HTML-escaped before it reaches `innerHTML`.
- Keys: `C` opens the chat for the selected bot. `ESC` closes it. While the chat is open, other village shortcuts are ignored.
- Code style follows the surrounding code: double quotes, semicolons, 2-space indent, short `//` or `/** */` comments that explain *why*, `node:test` with `assert/strict`.
- `pnpm typecheck` and `pnpm test` (what CI runs) must pass after every task.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Tool output containing HTML or script**, such as a `Read` of an `.html` file or a Bash command that prints `<script>`. It must show as literal text, never as markup. Tested in Task 5 (`textHtml`, `resultHtml`, `diffHtml`, `toolSummary` escape everything).
2. **Text that Claude Code injects as a "user" turn**, such as `<command-name>`, `<system-reminder>`, task notifications, `isMeta`, compact summaries, and interrupt markers. It must not appear as something the user typed. Tested in Task 2.
3. **Huge tool inputs**, such as a `Write` of a 2 MB file or a `MultiEdit` with large strings. They are capped like results, so a long session still opens fast. Tested in Task 2 (`capInput`).
4. **The daemon restarting while a chat is open.** `EventSource` reconnects and the backlog is sent again. The reader must not see duplicates. Tested in Task 5 (`Seen`); uuids are stable across daemon restarts.
5. **A subagent transcript that appears before its `.meta.json`, or a meta file that's unreadable.** The feed must not throw. It picks the subagent up on a later poll, including the lines written before the meta existed. Tested in Task 3.

**Known limitation:** an unfinished line over 8 MB is dropped by `JsonlTail`, so that tool card never gets a result. Claude Code already caps tool output well below this.

// Follows Claude Code's transcript files. Each read starts where the last one stopped, so
// following a long session only costs the bytes it appended since.
import { open } from "node:fs/promises";
import { isAbsolute } from "node:path";
import { StringDecoder } from "node:string_decoder";
import type { TitleSource } from "./bots.js";

const CHUNK = 1 << 20;
/** Title lines are short; a huge unfinished line is a tool result. */
const MAX_TITLE_LINE = 1 << 16;

/** Paths come from hook bodies and the session registry; anything else isn't a transcript. */
export const isTranscriptPath = (path: string) => isAbsolute(path) && path.endsWith(".jsonl");

/** Reads a JSONL file incrementally. The decoder holds a character split between chunks. */
export class JsonlTail {
  private offset = 0;
  private rest = "";
  private decoder = new StringDecoder("utf8");

  constructor(readonly path: string, private readonly maxLine: number) {}

  /**
   * Complete lines appended since the last call. A file that shrank was rewritten, so it is read
   * again from the start and `reset` is set. An unfinished line over maxLine becomes a stub that
   * won't parse, so a huge line costs no memory while it streams in.
   */
  async read(): Promise<{ lines: string[]; reset: boolean }> {
    const file = await open(this.path, "r");
    try {
      const { size } = await file.stat();
      const reset = size < this.offset;
      if (reset) {
        this.offset = 0;
        this.rest = "";
        this.decoder = new StringDecoder("utf8");
      }
      const lines: string[] = [];
      const buffer = Buffer.alloc(Math.min(CHUNK, size - this.offset));
      while (this.offset < size) {
        const { bytesRead } = await file.read(buffer, 0, Math.min(buffer.length, size - this.offset), this.offset);
        if (!bytesRead) break;
        this.offset += bytesRead;
        const parts = (this.rest + this.decoder.write(buffer.subarray(0, bytesRead))).split("\n");
        this.rest = parts.pop()!;
        if (this.rest.length > this.maxLine) this.rest = "\0";
        for (const part of parts) lines.push(part);
      }
      return { lines, reset };
    } finally {
      await file.close();
    }
  }
}

/** Claude Code writes `ai-title` lines as the session goes on and a `custom-title` line on /rename. */
export function titleIn(line: string): { title: string; source: TitleSource } | undefined {
  if (!line.includes("-title")) return;
  try {
    const entry = JSON.parse(line);
    if (entry.type === "custom-title" && typeof entry.customTitle === "string") return { title: entry.customTitle, source: "custom" };
    if (entry.type === "ai-title" && typeof entry.aiTitle === "string") return { title: entry.aiTitle, source: "ai" };
  } catch {}
}

const titleTails = new Map<string, JsonlTail>();

/** The titles appended to the transcript since the last call, oldest first. */
export async function newTitles(path: string): Promise<{ title: string; source: TitleSource }[]> {
  if (!isTranscriptPath(path)) return [];
  let tail = titleTails.get(path);
  if (!tail) titleTails.set(path, (tail = new JsonlTail(path, MAX_TITLE_LINE)));
  const found = [];
  for (const line of (await tail.read()).lines) {
    const t = titleIn(line);
    if (t) found.push(t);
  }
  return found;
}

export function forgetTranscript(path: string): void {
  titleTails.delete(path);
}
```

// Turns Claude Code transcript lines into chat entries for the web app's chat view. Pure, so the
// rules can be tested on lines copied from real transcripts.
import type { ChatEntry } from "@hamlet/shared";

/** Longest tool result or input string sent to the browser, so a 20 MB transcript still opens quickly. */
export const TEXT_CAP = 32 * 1024;

type Line = Record<string, any>;

const capped = (s: string) => (s.length > TEXT_CAP ? `${s.slice(0, TEXT_CAP)}\n… (truncated)` : s);

/** Caps every string in a tool input, at any depth: MultiEdit keeps its strings in `edits`. */
function capInput(v: unknown): unknown {
  if (typeof v === "string") return capped(v);
  if (Array.isArray(v)) return v.map(capInput);
  if (v && typeof v === "object") return Object.fromEntries(Object.entries(v).map(([k, x]) => [k, capInput(x)]));
  return v;
}

function resultText(content: unknown): string {
  if (typeof content === "string") return content;
  if (!Array.isArray(content)) return "";
  return content.map((c) => (c?.type === "text" ? String(c.text ?? "") : `[${c?.type ?? "content"}]`)).join("\n");
}

/** Claude Code wraps commands, reminders and notifications in tags; only what the user typed is a prompt. */
const typed = (t: unknown): t is string => typeof t === "string" && t.trim() !== "" && !t.trimStart().startsWith("<");
const INTERRUPTED = /^\[Request interrupted by user/;

export function duration(ms: number): string {
  const s = Math.round(ms / 1000);
  if (s < 60) return `${s}s`;
  if (s < 3600) return `${Math.floor(s / 60)}m ${s % 60}s`;
  return `${Math.floor(s / 3600)}h ${Math.floor((s % 3600) / 60)}m`;
}

function notice(e: Line): { text: string; level: "info" | "error" } | undefined {
  switch (e.subtype) {
    case "api_error":
      return { text: `API error: ${e.error?.formatted ?? e.error?.message ?? "request failed"}`, level: "error" };
    case "informational":
      return typeof e.content === "string" && e.content ? { text: e.content, level: "info" } : undefined;
    case "local_command": {
      const text = String(e.content ?? "").replace(/<[^>]+>/g, "").trim();
      return text ? { text, level: "info" } : undefined;
    }
    case "turn_duration":
      return typeof e.durationMs === "number" ? { text: `Turn took ${duration(e.durationMs)}`, level: "info" } : undefined;
    // Not seen in local transcripts yet; this is the subtype Claude Code gives its compaction marker.
    case "compact_boundary":
      return { text: "Context compacted", level: "info" };
  }
}

/** The chat entries in one transcript line. `parent` is set for a subagent's transcript: the call that started it. */
export function toEntries(line: string, parent?: string): ChatEntry[] {
  let e: Line;
  try {
    e = JSON.parse(line);
  } catch {
    return [];
  }
  if (!e || typeof e !== "object" || typeof e.uuid !== "string") return [];
  // Older Claude Code versions wrote subagent turns into the main transcript.
  if (!parent && e.isSidechain) return [];
  const base = (i: number) => ({ uuid: `${e.uuid}:${i}`, at: String(e.timestamp ?? ""), ...(parent ? { parent } : {}) });
  const content = e.message?.content;
  const out: ChatEntry[] = [];
  if (e.type === "user" && !e.isMeta && !e.isCompactSummary) {
    const blocks: Line[] = typeof content === "string" ? [{ type: "text", text: content }] : Array.isArray(content) ? content : [];
    blocks.forEach((c, i) => {
      if (c?.type === "tool_result") {
        const text = resultText(c.content);
        const cut = text.length > TEXT_CAP;
        out.push({
          ...base(i),
          kind: "result",
          toolUseId: String(c.tool_use_id),
          text: cut ? text.slice(0, TEXT_CAP) : text,
          isError: c.is_error === true,
          ...(cut ? { truncated: Buffer.byteLength(text) } : {}),
        });
      } else if (c?.type === "text" && INTERRUPTED.test(String(c.text))) out.push({ ...base(i), kind: "notice", text: "Interrupted", level: "info" });
      else if (c?.type === "text" && typed(c.text)) out.push({ ...base(i), kind: "prompt", text: c.text });
    });
  } else if (e.type === "assistant" && Array.isArray(content)) {
    content.forEach((c: Line, i: number) => {
      if (c?.type === "text" && typeof c.text === "string" && c.text.trim()) out.push({ ...base(i), kind: "text", text: c.text });
      else if (c?.type === "thinking" && typeof c.thinking === "string" && c.thinking.trim()) out.push({ ...base(i), kind: "thinking", text: c.thinking });
      // A fork's transcript starts with a copy of the call that started it.
      else if (c?.type === "tool_use" && c.id !== parent) out.push({ ...base(i), kind: "tool", id: String(c.id), name: String(c.name), input: capInput(c.input ?? {}) });
    });
  } else if (e.type === "system") {
    const n = notice(e);
    if (n) out.push({ ...base(0), kind: "notice", ...n });
  }
  return out;
}
```

```ts
// Follows one session's transcript, and its subagents' transcripts, for the chat view. Every open
// chat on a session shares one feed, which keeps the entries so another viewer gets them at once.
import { readdir, readFile } from "node:fs/promises";
import { join } from "node:path";
import type { ChatEntry, ChatEvent } from "@hamlet/shared";
import { toEntries } from "./chat.js";
import { JsonlTail } from "./transcript.js";

/** Entries per SSE message, so a long backlog renders progressively. */
export const BATCH = 500;
/** Tool results can be megabytes; an unfinished line over this is dropped. */
const MAX_LINE = 8 << 20;

type Listener = (e: ChatEvent) => void;

export class ChatFeed {
  readonly entries: ChatEntry[] = [];
  private main: JsonlTail;
  private subagents = new Map<string, { tail: JsonlTail; parent: string }>();
  private listeners = new Set<Listener>();
  private failed = false;

  constructor(readonly path: string, private readonly onError: (e: unknown) => void = () => {}) {
    this.main = new JsonlTail(path, MAX_LINE);
  }

  get viewers(): number {
    return this.listeners.size;
  }

  /** Sends everything read so far, then each change. Returns the unsubscribe function. */
  subscribe(listener: Listener): () => void {
    for (let i = 0; i < this.entries.length; i += BATCH) listener({ entries: this.entries.slice(i, i + BATCH) });
    if (this.failed) listener({ error: "unreadable" });
    this.listeners.add(listener);
    return () => this.listeners.delete(listener);
  }

  /** Reads what the main transcript and each subagent transcript appended since the last poll. */
  async poll(): Promise<void> {
    let read: { lines: string[]; reset: boolean };
    try {
      read = await this.main.read();
    } catch (e) {
      if (!this.failed) {
        this.failed = true;
        this.onError(e);
        this.emit({ error: "unreadable" });
      }
      return;
    }
    this.failed = false;
    if (read.reset) {
      this.entries.length = 0;
      this.subagents.clear();
      this.emit({ reset: true });
    }
    const fresh = read.lines.flatMap((line) => toEntries(line));
    for (const sub of await this.subagentTails()) {
      try {
        for (const line of (await sub.tail.read()).lines) fresh.push(...toEntries(line, sub.parent));
      } catch (e) {
        this.onError(e);
      }
    }
    for (const entry of fresh) this.entries.push(entry);
    for (let i = 0; i < fresh.length; i += BATCH) this.emit({ entries: fresh.slice(i, i + BATCH) });
  }

  /** Subagents write <session>/subagents/agent-<id>.jsonl beside a meta file naming the call that started them. */
  private async subagentTails() {
    const dir = join(this.path.replace(/\.jsonl$/, ""), "subagents");
    for (const name of await readdir(dir).catch(() => [] as string[])) {
      const id = /^agent-(.+)\.jsonl$/.exec(name)?.[1];
      if (!id || this.subagents.has(id)) continue;
      try {
        const meta = JSON.parse(await readFile(join(dir, `agent-${id}.meta.json`), "utf8"));
        if (typeof meta.toolUseId === "string") this.subagents.set(id, { tail: new JsonlTail(join(dir, name), MAX_LINE), parent: meta.toolUseId });
      } catch {} // the meta file may not be written yet; the next poll tries again
    }
    return [...this.subagents.values()];
  }

  private emit(e: ChatEvent): void {
    for (const listener of this.listeners) listener(e);
  }
}

/** One feed per session, polled while anyone watches it and dropped a while after the last viewer leaves. */
export class Feeds {
  private feeds = new Map<string, { feed: ChatFeed; timer: NodeJS.Timeout; idleSince?: number }>();

  constructor(
    private readonly onError: (sessionId: string, e: unknown) => void,
    private readonly everyMs = 500,
    private readonly graceMs = 30_000,
  ) {}

  get size(): number {
    return this.feeds.size;
  }

  subscribe(sessionId: string, path: string, listener: Listener): () => void {
    let f = this.feeds.get(sessionId);
    // A hook's path replaces one found in the session registry.
    if (f && f.feed.path !== path) this.drop(sessionId), (f = undefined);
    if (!f) {
      const feed = new ChatFeed(path, (e) => this.onError(sessionId, e));
      f = { feed, timer: this.start(sessionId, feed) };
      this.feeds.set(sessionId, f);
    }
    return f.feed.subscribe(listener);
  }

  drop(sessionId: string): void {
    const f = this.feeds.get(sessionId);
    if (!f) return;
    clearInterval(f.timer);
    this.feeds.delete(sessionId);
  }

  private start(sessionId: string, feed: ChatFeed): NodeJS.Timeout {
    let busy = false;
    const tick = async () => {
      if (busy) return;
      busy = true;
      try {
        await feed.poll();
      } finally {
        busy = false;
      }
      const f = this.feeds.get(sessionId);
      if (!f || f.feed !== feed) return;
      if (feed.viewers) delete f.idleSince;
      else if ((f.idleSince ??= Date.now()) + this.graceMs <= Date.now()) this.drop(sessionId);
    };
    void tick();
    const timer = setInterval(tick, this.everyMs);
    timer.unref();
    return timer;
  }
}
```

// Pure helpers for the chat view: what a tool card says, and the HTML for text, diffs and results.
// Transcript content is untrusted, so every string goes through esc() before it becomes HTML.
import type { ChatEntry } from "@hamlet/shared/world";

export const esc = (s: string) => s.replace(/[&<>"']/g, (c) => `&#${c.charCodeAt(0)};`);

const str = (v: unknown) => (typeof v === "string" ? v : "");

export const isAgent = (name: string) => name === "Agent" || name === "Task";

/** One line saying what a tool call is about, such as the command or the file. */
export function toolSummary(name: string, input: unknown): string {
  const i = (input ?? {}) as Record<string, unknown>;
  const text =
    name === "Bash" ? str(i.command).split("\n")[0]!
    : isAgent(name) ? str(i.description)
    : str(i.file_path) || str(i.notebook_path) || str(i.pattern) || str(i.url) || str(i.query) || str(i.skill) || str(i.description);
  return text.length > 120 ? `${text.slice(0, 119)}…` : text;
}

/** Claude's text: paragraphs keep their line breaks, fenced code becomes a code block. */
export function textHtml(text: string): string {
  const out: string[] = [];
  let prose: string[] = [];
  let code: string[] | undefined;
  const flush = () => {
    const p = prose.join("\n").trim();
    if (p) out.push(`<p class="say">${esc(p)}</p>`);
    prose = [];
  };
  for (const line of text.split("\n")) {
    if (!line.trimStart().startsWith("```")) (code ?? prose).push(line);
    else if (code) out.push(`<pre class="code">${esc(code.join("\n"))}</pre>`), (code = undefined);
    else flush(), (code = []);
  }
  if (code) out.push(`<pre class="code">${esc(code.join("\n"))}</pre>`);
  flush();
  return out.join("");
}

type Edit = { old_string?: unknown; new_string?: unknown };

/** Edit, MultiEdit and Write as removed (-) then added (+) lines: a listing, not a minimal diff. */
export function diffHtml(name: string, input: unknown): string | undefined {
  const i = (input ?? {}) as Record<string, unknown>;
  const lines = (sign: "-" | "+", v: unknown) =>
    str(v) ? str(v).split("\n").map((l) => `<span class="${sign === "-" ? "del" : "add"}">${sign} ${esc(l)}</span>`) : [];
  const hunk = (e: Edit) => `<pre class="diff">${[...lines("-", e.old_string), ...lines("+", e.new_string)].join("")}</pre>`;
  if (name === "Edit") return hunk(i);
  if (name === "MultiEdit" && Array.isArray(i.edits)) return (i.edits as Edit[]).map(hunk).join("");
  if (name === "Write") return hunk({ new_string: i.content });
}

/** The expanded body of a tool card, above its result. */
export function inputHtml(name: string, input: unknown): string {
  const i = (input ?? {}) as Record<string, unknown>;
  if (name === "Bash") return `<pre class="code">$ ${esc(str(i.command))}</pre>`;
  if (isAgent(name)) return `<pre class="code">${esc(str(i.prompt))}</pre>`;
  const diff = diffHtml(name, input);
  if (diff !== undefined) return `<p class="path">${esc(str(i.file_path))}</p>${diff}`;
  return `<pre class="code">${esc(JSON.stringify(input, null, 2))}</pre>`;
}

export function bytes(n: number): string {
  return n >= 1 << 20 ? `${(n / (1 << 20)).toFixed(1)} MB` : `${Math.round(n / 1024)} KB`;
}

export function resultHtml(r: Extract<ChatEntry, { kind: "result" }>): string {
  const note = r.truncated ? `<p class="note">Result truncated (${bytes(r.truncated)})</p>` : "";
  return `<pre class="out${r.isError ? " err" : ""}">${esc(r.text) || "(no output)"}</pre>${note}`;
}

/** Entries already shown, by uuid, so a reconnect that resends the backlog adds nothing twice. */
export class Seen {
  private ids = new Set<string>();

  fresh(entries: ChatEntry[]): ChatEntry[] {
    return entries.filter((e) => !this.ids.has(e.uuid) && !!this.ids.add(e.uuid));
  }

  clear(): void {
    this.ids.clear();
  }
}
```

```ts
// The chat overlay: a session's conversation, read live from its transcript through the daemon.
// Entries are only ever appended; tool cards build their bodies when first opened, so a long
// session stays light.
import { API_PREFIX, type Bot, type ChatEntry, type ChatEvent } from "@hamlet/shared/world";
import { esc, inputHtml, isAgent, resultHtml, Seen, textHtml, toolSummary } from "./chat-format.js";

type Tool = Extract<ChatEntry, { kind: "tool" }>;
type Result = Extract<ChatEntry, { kind: "result" }>;

const root = document.querySelector<HTMLElement>(".chat")!;
/** Entries handled per animation frame, so a long backlog never freezes the tab. */
const PER_FRAME = 200;

let source: EventSource | undefined;
let sessionId: string | undefined;
let log: HTMLElement | undefined;
const seen = new Seen();
const cards = new Map<string, { el: HTMLDetailsElement; tool: Tool }>();
const results = new Map<string, Result>();
/** Subagent entries whose Agent card isn't on screen yet. */
const orphans = new Map<string, ChatEntry[]>();
let queue: ChatEntry[] = [];
let scheduled = false;
let following = true;

export const chatOpen = () => !root.hidden;
export const chatSession = () => (chatOpen() ? sessionId : undefined);

export function openChat(bot: Bot, name: string): void {
  closeChat();
  sessionId = bot.sessionId;
  root.hidden = false;
  root.innerHTML = `<header>
      <span class="dot"></span>
      <span class="head"><span class="repo"></span><span class="subtitle"></span></span>
      <button class="pill" data-act="chat-close" hidden></button>
      <button class="ghost" data-act="chat-close" aria-label="Close">ESC</button>
    </header>
    <div class="log" tabindex="0"></div>
    <p class="note" hidden></p>
    <button class="jump primary" data-act="chat-jump" hidden>↓ NEW MESSAGES</button>`;
  log = root.querySelector<HTMLElement>(".log")!;
  log.addEventListener("scroll", () => {
    following = log!.scrollHeight - log!.scrollTop - log!.clientHeight < 40;
    if (following) root.querySelector<HTMLElement>(".jump")!.hidden = true;
  });
  updateChat(bot, name);
  source = new EventSource(`${API_PREFIX}/sessions/${encodeURIComponent(bot.sessionId)}/chat`);
  source.onmessage = (e) => receive(JSON.parse(e.data) as ChatEvent);
  log.focus();
}

export function closeChat(): void {
  source?.close();
  source = undefined;
  sessionId = undefined;
  reset();
  log = undefined;
  root.hidden = true;
  root.innerHTML = "";
}

/** Header only: the name, place, title and state can change while the chat is open. */
export function updateChat(bot: Bot | undefined, name: string): void {
  const header = root.querySelector("header");
  if (!header) return;
  header.className = bot?.state ?? "ended";
  header.querySelector(".repo")!.innerHTML = bot ? `${esc(name)} <span class="branch">${esc(bot.repo)} / ${esc(bot.branch)}</span>` : `${esc(name)} <span class="branch">ended</span>`;
  header.querySelector(".subtitle")!.textContent = bot?.title ?? "";
  const pill = header.querySelector<HTMLElement>(".pill")!;
  pill.hidden = bot?.state !== "needs_input";
  pill.textContent = bot?.permission ? `WAITING · ${bot.permission.toolName}` : "WAITING";
  pill.title = "Close the chat to answer in the bubble";
}

export function jumpToEnd(): void {
  if (!log) return;
  log.scrollTop = log.scrollHeight;
  following = true;
  root.querySelector<HTMLElement>(".jump")!.hidden = true;
}

function reset(): void {
  if (log) log.innerHTML = "";
  seen.clear();
  cards.clear();
  results.clear();
  orphans.clear();
  queue = [];
}

function showNote(text: string): void {
  const note = root.querySelector<HTMLElement>(".note");
  if (!note) return;
  note.hidden = !text;
  note.textContent = text;
}

function receive(e: ChatEvent): void {
  if ("reset" in e) return reset();
  if ("error" in e)
    return showNote(e.error === "no-transcript" ? "Waiting for this session's transcript…" : "Couldn't read this session's transcript. The daemon log has the error.");
  showNote("");
  for (const entry of seen.fresh(e.entries)) queue.push(entry);
  if (!scheduled) (scheduled = true), requestAnimationFrame(drain);
}

function drain(): void {
  scheduled = false;
  if (!log) return;
  const batch = queue.splice(0, PER_FRAME);
  for (const entry of batch) place(entry);
  if (following) log.scrollTop = log.scrollHeight;
  else if (batch.length) root.querySelector<HTMLElement>(".jump")!.hidden = false;
  if (queue.length) (scheduled = true), requestAnimationFrame(drain);
}

function place(entry: ChatEntry): void {
  if (entry.kind === "result") {
    results.set(entry.toolUseId, entry);
    return fillResult(entry.toolUseId);
  }
  const parent = entry.parent ? cards.get(entry.parent) : undefined;
  if (entry.parent && !parent) return void orphans.set(entry.parent, [...(orphans.get(entry.parent) ?? []), entry]);
  (parent?.el.querySelector<HTMLElement>(".sub") ?? log!).append(element(entry));
  if (entry.kind !== "tool") return;
  for (const child of orphans.get(entry.id) ?? []) place(child);
  orphans.delete(entry.id);
  fillResult(entry.id);
}

function element(entry: Exclude<ChatEntry, Result>): HTMLElement {
  if (entry.kind === "tool") return toolCard(entry);
  const el = document.createElement(entry.kind === "thinking" ? "details" : "div");
  if (entry.kind === "prompt") (el.className = "prompt"), (el.innerHTML = `<span class="caret">&gt;</span><p>${esc(entry.text)}</p>`);
  else if (entry.kind === "text") (el.className = "reply"), (el.innerHTML = textHtml(entry.text));
  else if (entry.kind === "thinking") (el.className = "thinking"), (el.innerHTML = `<summary>Thinking</summary><p class="say">${esc(entry.text)}</p>`);
  else (el.className = `notice ${entry.level}`), (el.innerHTML = `<span>${esc(entry.text)}</span>`);
  return el;
}

function toolCard(tool: Tool): HTMLDetailsElement {
  const el = document.createElement("details");
  el.className = "tool";
  el.dataset.state = "running";
  el.innerHTML = `<summary><span class="name">${esc(tool.name)}</span> <span class="what">${esc(toolSummary(tool.name, tool.input))}</span><span class="status"></span></summary><div class="input"></div>${isAgent(tool.name) ? `<div class="sub"></div>` : ""}<div class="result"></div>`;
  el.addEventListener("toggle", () => {
    if (!el.open) return;
    const input = el.querySelector<HTMLElement>(".input")!;
    if (!input.innerHTML) input.innerHTML = inputHtml(tool.name, tool.input);
    fillResult(tool.id);
  });
  cards.set(tool.id, { el, tool });
  return el;
}

/** Marks the card done or failed, and fills in the result once the card is open. */
function fillResult(toolUseId: string): void {
  const card = cards.get(toolUseId);
  const r = results.get(toolUseId);
  if (!card || !r) return;
  card.el.dataset.state = r.isError ? "error" : "done";
  const slot = card.el.querySelector<HTMLElement>(".result")!;
  if (card.el.open && !slot.innerHTML) slot.innerHTML = resultHtml(r);
}
